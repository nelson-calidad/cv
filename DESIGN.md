# Compound — Style Reference & Design System
> Adapted for Nelson Notario Professional Portfolio — Engineering, Quality & AI-driven Solutions.
> Ink-on-paper wealth journal aesthetic: quiet editorial system, achromatic precision, ethereal shadows, and warm cream notification accent.

## Core Design Tokens

### Colors
- **Ink (`--color-ink`):** `#171717` — Primary text, filled pill buttons, navigation emphasis, solid logo wordmark.
- **Paper (`--color-paper`):** `#ffffff` — Page canvas, primary cards, clean background surfaces.
- **Graphite Hairline (`--color-graphite-hairline`):** `#e5e7eb` — Structural borders, dividers, card edges, input lines.
- **Vellum (`--color-vellum`):** `#f3f3f3` — Secondary surface fills, alternate section band, subtle hover washes.
- **Slate (`--color-slate`):** `#6f6f6f` — Secondary body text, metadata, descriptions, quiet subtitle labels.
- **Pewter (`--color-pewter`):** `#5e5e5e` — Helper text, micro-copy, emphasized secondary descriptions.
- **Ash (`--color-ash`):** `#a0a0a0` — Tertiary text, inactive badges, quietest readable grey.
- **Carbon (`--color-carbon`):** `#222222` — Dark section background, high-contrast footer, vector icons.
- **Stone (`--color-stone`):** `#c7c7c7` — 3D gradient endpoints, decorative depth, ribbon shading.
- **Cream Notice (`--color-cream-notice`):** `#ffe9bf` — Warm top announcement bar, single chromatic accent in the system.

### Typography
- **Display Headings:** 'Manrope' / 'Monument Grotesk' style geometric grotesque (`--font-display`), tight line heights (`1.05 - 1.15`), architectural tracking (`-0.03em`).
- **Body & Secondary:** 'DM Sans' (`--font-body`), high legibility, `16.5px` base text with `1.7` line height.
- **Type Scale:**
  - `caption`: 12px
  - `body-sm`: 14px - 14.5px
  - `body`: 16.5px
  - `subheading`: 18px
  - `heading-sm`: 24px - 30px
  - `heading`: 36px - 48px
  - `display`: 56px - 68px

### Elevation & Multi-layer Ethereal Shadows
- `--shadow-xl`: `rgba(0, 0, 0, 0.01) 0px 128px 51px 0px, rgba(0, 0, 0, 0.02) 0px 72px 43px 0px, rgba(0, 0, 0, 0.03) 0px 32px 32px 0px, rgba(0, 0, 0, 0.04) 0px 8px 18px 0px`
- `--shadow-xl-3`: `rgba(207, 207, 207, 0.01) 0px 132px 53px 0px, rgba(207, 207, 207, 0.05) 0px 74px 44px 0px, rgba(207, 207, 207, 0.09) 0px 33px 33px 0px, rgba(207, 207, 207, 0.1) 0px 8px 18px 0px`

### Border Radii
- Cards: `20px` (`--radius-card`)
- Large Cards: `24px` (`--radius-lg-card`)
- Pills & Buttons: `9999px` (`--radius-pill`)
- Small Badges: `8px` (`--radius-sm`)

### 3D Visual Signature
- Hybrid 3D kinetic structure uniting Industrial Engineering lattice nodes with a floating translucent ribbon helix (`#c7c7c7` to `#171717`), smooth mouse tracking lerp, and weightless floating oscillation.
